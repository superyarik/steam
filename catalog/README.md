# Сборка PDF-каталога 3D-моделей

```bash
cd catalog
python3 build.py
```

Результат: `../3d-models-catalog.pdf`. Нужны Python 3 с Pillow, Node.js и Playwright с Chromium. Список моделей — в `models.py`.

## Откуда берутся картинки

| Площадка | Как получить картинку |
|---|---|
| Printables | Автоматически через публичный API, вместе со статистикой |
| MakerWorld, Cults3D | Вручную: сайты закрыты от автоматических запросов, публичного API у MakerWorld нет |
| Thingiverse | Автоматически, если задан `THINGIVERSE_TOKEN`; иначе вручную |

Если у модели нет картинки, в PDF вместо неё стоит плашка с названием площадки, а сама модель попадает в `NEED-IMAGES.md`. Там же указан её ключ (`mw-1742588`, `tv-4283898`, `cults-karcher-puzzi-filter`).

### Способ 1: файл в папку `images/`

Откройте модель по ссылке из `NEED-IMAGES.md`, сохраните главную картинку (правый клик → «Сохранить картинку как…») под именем `images/<ключ>.jpg`. Подойдут также `.png` и `.webp`. Размер приводится к нужному автоматически.

### Способ 2: ссылка на картинку в `image-urls.txt`

1. Откройте страницу модели в своём браузере.
2. Запустите `grab-image.js`: вставьте его в консоль (F12 → Console) или сохраните как закладку с адресом `javascript:` + код из файла.
3. Скрипт скопирует в буфер строку `<ключ> <url картинки>`. Вставьте её в `image-urls.txt`, по одной строке на модель.

Если CDN площадки не отдаёт картинку сборщику, в консоли будет «не удалось скачать». Тогда используйте способ 1.

### Способ 3: Thingiverse API

Создайте бесплатное приложение на https://www.thingiverse.com/developers, получите App Token и запустите:

```bash
THINGIVERSE_TOKEN=<токен> python3 build.py
```
